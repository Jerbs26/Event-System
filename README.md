# EventHub

A full-stack PHP event management system with user authentication, event registration, admin controls, and email notifications.

---

## Features

- User registration and login with session-based auth
- Remember me cookie and forgot password via OTP email
- Browse, register, and unregister from events
- Admin panel to manage events, users, and reports
- Dark-themed responsive UI

---

## Database

Five tables: `users`, `events`, `event_registrations`, `password_resets`, `OTP_verification`

---

## Dependencies

- `phpmailer/phpmailer` — email delivery for OTP and notifications

---

## Author

The Project built with PHP, MySQL, and HTML/CSS/JS.
